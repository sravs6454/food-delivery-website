# 🍔 Food Delivery Website

A full-stack Food Delivery Web Application built using the **MERN Stack**. The platform allows users to browse restaurants, order food online, manage their cart, and track orders. It also includes an admin panel for managing menu items and orders.

---

## ✨ Features

### 👤 User Features
- User Registration & Login
- Browse Food Menu
- Search & Filter Food Items
- Add to Cart
- Place Orders
- Order History
- Responsive UI

### 👨‍💼 Admin Features
- Add Food Items
- Update Menu
- Delete Food Items
- Manage Orders
- View Customer Orders

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/sravs6454/food-delivery-website.git
```

```bash
cd food-delivery-website
```

---

## Backend Setup

```bash
cd backend
npm install
npm start
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Admin Panel

```bash
cd admin
npm install
npm run dev
```
